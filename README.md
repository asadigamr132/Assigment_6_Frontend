# Assignment 6 — jQuery

A simple multi-page project for practicing jQuery selectors, effects, DOM manipulation and animations.

## Pages
- `index.html` — navigation and task overview
- `pages/task0-1.html` — setup, selectors and CSS
- `pages/task2-4.html` — visibility, fade and slide effects
- `pages/task5-7.html` — DOM changes, attributes and form interaction
- `pages/task8-10.html` — basic, sequential and combined animations
- `pages/task11.html` — image gallery mini project

## Run
Open `index.html` in a browser. jQuery is loaded from the official CDN, so an internet connection is needed.
